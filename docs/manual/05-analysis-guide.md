# 05 Analysis Guide

The Analysis page is the main research and interpretation surface for diagnostics, intelligence, and tuning.

## Main Goals

- Understand system performance
- Review diagnostics and confidence surfaces
- Interpret launch quality patterns
- Apply tuning suggestions safely

Screenshot: `assets/screenshots/analysis/analysis-page-overview.png`

## Core Sections

### Performance analytics

- summary
- grouped performance
- win/loss context
- profit-factor and drawdown interpretation

### Tuning suggestions

Suggestions are generated from observed outcomes and can be applied directly. Apply them carefully and review the side effects in the settings reference.

Screenshot: `assets/screenshots/analysis/tuning-suggestions.png`

### Price diagnostics

The price system exposes selected price, confidence, rejection reasons, and candidate price sources.

### Pump.fun intelligence

This section summarizes creator reuse, metadata quality, launch structure, and related intelligence signals.

## Recommended Workflow

1. Review overall performance summary.
2. Inspect price-confidence and data-quality anomalies.
3. Review Pump.fun intelligence patterns.
4. Apply or note tuning suggestions.
5. Save meaningful strategy presets after validation.

## When To Use Analysis

- After a monitor session
- Before changing thresholds
- After major backtests
- When confidence or quality degrades
- When evaluating a new strategy profile
